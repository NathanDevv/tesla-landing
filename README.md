# 🚗 Tesla Clone Website

This project is a **clone of the official Tesla website**, built as a learning exercise using **[Astro](https://astro.build/)** and **[Tailwind CSS](https://tailwindcss.com/)**. It replicates the clean, minimal design and layout of Tesla's landing page, including car models, energy products, and navigation.

## 📸 Screenshot

![Website Preview](./screenshot.png)

## 🚀 Features

- Fully responsive layout
- Component-based file structure
- Models and energy product sections
- Modern and minimal Tesla-like design
- Fast build performance using Astro

## 🛠️ Technologies Used

- ⚡ [Astro](https://astro.build/)
- 🎨 [Tailwind CSS](https://tailwindcss.com/)
- ✨ TypeScript
- 🧩 Modular .astro components
